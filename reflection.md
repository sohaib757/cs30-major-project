# Reflection

## What advice would you give yourself if you were to start a project like this again?
- Try to make a game that would challenge me more.
- A game or simulation that would have more cool features and better user interaction.
- Dedicate more time to my project.
- Incorporate at least one or two nice to have features.
- Focus on more extra for experts features rather than just doing the bare minimum.
- Have more fun doing it.
- Focus more on the appearance of the game not just functionality.

## Did you complete everything in your needs to have list?
- Yes, I did complete everything in my needs to have list.

## What was the hardest part of the project?
- Getting the enemies to follow a fixed pathway.
- Turret direction and rotating logic (vectors).
- Scaling the difficulty of my game (enemy hp, turret damage, fire rate, etc).
- Hp bar logic.
- Collision detection.

## Were there any problems you could not solve?
- My path logic and enemy movement is flawed and I wasn't able to figure out a way for the enemies to be able to move from point to point unless their speed was set to 1.
- How to best scale the difficulty of the game.
- Coming up with new features to make my game better. Instead of just adding more of the same thing (more turrets, more maps) I wanted to add new fun/unique features but I couldn't come up with any.
