# Major Project Proposal

## Description
- Make a tower defense game

## Needs to Have
- A tank/character that the user can choose from for defense.
- Enemies that spawn in and progressively get harder to kill. (waves)
- A path for the enemies to follow.
- Tower health that decreases whenever breached by an enemy.
- Background music and sound effects.

## Nice to Have
- Various maps or paths to choose from.
- Multiple tanks/characters for the user to choose from.
- Bosses at the end of every 5 or 10 waves.
- Enemies that differ in behaviour. (higher HP, faster speed, shields, etc.)
- A leaderboard that keeps track of longest survival time. (in waves)
